# 📚 Book Recommendation System

Aplikasi pencarian dan penemuan buku yang memudahkan pengguna mencari buku berdasarkan judul atau nama penulis, serta menemukan rekomendasi bacaan baru secara efisien[cite: 11, 12].

---

## ✨ Fitur Utama

- **Pencarian Cepat:** Cari koleksi buku berdasarkan judul atau nama penulis[cite: 11].
- **Rekomendasi Terarah:** Membantu eksplorasi karya lengkap dari seorang penulis maupun buku terkait dalam satu tempat[cite: 11, 12].
- **Daftar Favorit:** Simpan buku-buku pilihan ke dalam daftar bacaan favorit (*My Favorite Books*)[cite: 12].
- **Antarmuka Responsif:** Tampilan modern, bersih, dan mudah digunakan[cite: 11].

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **API:** Book Database API (atau sesuaikan dengan sumber data kamu)
